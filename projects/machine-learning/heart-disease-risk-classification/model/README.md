# Heart Disease Risk Classification

## Problem Understanding

* **Business Understanding:** Proyek ini bertujuan untuk mengatasi keterlambatan identifikasi awal risiko penyakit jantung yang berpotensi meningkatkan komplikasi medis pada pasien. Solusi ini dibangun untuk membantu tenaga medis melakukan skrining awal berbasis data secara cepat dan objektif.
* **Define ML Task:** Permasalahan ini dirumuskan sebagai **Supervised Learning — Binary Classification** untuk memprediksi status risiko penyakit jantung (`target`: 0 atau 1) berdasarkan data klinis pasien, dengan fokus evaluasi pada metrik **Recall** guna meminimalkan kasus *false negative*.
